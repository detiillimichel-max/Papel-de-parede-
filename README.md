# Papel-de-parede-

Coleção de papéis de parede fofos, animados e estáticos — criados para celular, com estilo kawaii, pastel e temas originais.

> Projeto pessoal do Michel Detilli (@detillimichel) — feito com carinho para compartilhar artes leves que alegram a tela.

🌐 **Veja ao vivo:** https://detiillimichel-max.github.io/Papel-de-parede-/

---

## ✨ O que tem aqui

- **10+ wallpapers** em PNG otimizados para celular (9:16)
- **Versões animadas** em GIF (< 25 MB) com movimentos sutis:
  - borboletas batendo asas
  - gotas escorrendo
  - planetas em pêndulo orbital
  - personagens chibi (coelhinha, anjinha, ruivinha)
- **Galeria web** simples em `index.html` — abre direto no GitHub Pages
- Tudo 100% original (sem cópia de personagens protegidos)

Arquivos principais:
```
papel1.png  … papel10.png   # wallpapers estáticos
index.html                  # galeria
README.md                   # este arquivo
```

---

## 📱 Como usar

1. Acesse a galeria: https://detiillimichel-max.github.io/Papel-de-parede-/
2. Toque e segure na imagem > "Salvar imagem"
3. No celular: Definições > Tela de fundo > escolha a imagem

Para GIFs animados (se usar como live wallpaper no Android):
- Baixe o .gif da pasta `/animados` (em breve)
- Use apps como "GIF Live Wallpaper"

## 🎨 Estilo

- Paleta pastel (rosa, lilás, azul bebê)
- Personagens originais fofos
- Animações lentas e suaves (nada piscando rápido)
- Foco em leveza e conforto visual

## 🚀 Como contribuir

Quer sugerir um tema?
1. Abra uma Issue com a ideia (ex: "borboleta roxa com chuva")
2. Ou faça fork e envie um PR com seu `papel11.png`

Regras rápidas:
- Resolução recomendada: 1080×1920 ou 1440×3120
- Tamanho < 3 MB (PNG) / < 25 MB (GIF)
- Sem marcas d'água de terceiros
